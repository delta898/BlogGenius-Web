# Operations

안전하게 반복할 수 있어야 하는 운영 절차를 기록한다.

- 환경별 배포와 preflight
- Database migration과 복구
- Secret 등록과 rotation
- 관리자 access provisioning과 회수
- 장애 대응, rollback과 incident follow-up

실제 credential, 개인정보, 내부 접근 token 또는 악용 가능한 값을 문서에 포함하지 않는다.
