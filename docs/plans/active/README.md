# Active Development Records

진행 중인 큰 작업과 feature branch별 개발 기록을 둔다.

파일명은 `YYYY-MM-DD-normalized-purpose-development.md` 형식을 기본으로 한다.

## Required Sections

```markdown
# <Title>

## Status
- Branch:
- Base/parent branch:
- Started:
- Status:

## User Need

## Goal

## Scope

## Non-Goals

## Boundaries and Risks

## Proposed Design

## Stages

## Decisions and Alternatives

## Progress and Corrections

## Verification

## Remaining Risks and Follow-up

## Result
```

중요한 진행, 실패, 결정과 검증 결과를 작업 중에 갱신한다. 작업이 완료되면 안정된 내용을
canonical 문서로 승격하고 개발 기록은 `docs/plans/archive/`로 이동한다.
